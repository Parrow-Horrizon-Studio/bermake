Third-party components bundled with Bermake for Windows
=======================================================

Bermake itself is licensed under the GNU General Public License v3.0 or later
(LICENSE.txt). The Windows build also contains the following components,
each under its own licence. The exact version of each is listed under
"Versions in this build" at the end of this file, which is written when the
build is made. Licence texts are in the licenses folder beside this file
unless an entry says otherwise. Paths below are relative to this folder.

The GNU Lesser General Public License v3 (licenses\LGPL-3.0.txt) is a set of
additional permissions on top of the GNU GPL v3, whose text is LICENSE.txt.

Qt 6
  Licence: GNU LGPL v3 (licenses\LGPL-3.0.txt)
  Files:   _internal\PySide6\Qt6*.dll and _internal\PySide6\plugins\
  Source:  https://download.qt.io/official_releases/qt/
  Qt is dynamically linked. Its libraries are the Qt6*.dll files and plugins
  listed above, and you may replace them with your own builds of the same Qt
  version.

PySide6 and shiboken6
  Licence: GNU LGPL v3 (licenses\LGPL-3.0.txt)
  Files:   _internal\PySide6\*.pyd, _internal\PySide6\pyside6.abi3.dll,
           _internal\shiboken6\
  Source:  https://code.qt.io/cgit/pyside/pyside-setup.git/

Python runtime
  Licence: Python Software Foundation License Version 2
  Text:    licenses\Python\LICENSE.txt, which also carries the licences of
           components the Windows build of Python bundles, such as libffi
           (MIT) and bzip2. Three libraries compiled into standard library
           modules are not covered by that file and have their own entries
           below: expat, mpdecimal and liblzma.
  Files:   _internal\python313.dll, _internal\python3.dll,
           _internal\base_library.zip, the standard library modules
           _internal\*.pyd, and _internal\libffi-8.dll (libffi, MIT)
  Source:  https://www.python.org/

expat (compiled into Python's XML parser module)
  Licence: MIT (licenses\expat\COPYING.txt)
  Files:   _internal\pyexpat.pyd
  Source:  https://libexpat.github.io/

mpdecimal (compiled into Python's decimal module)
  Licence: BSD 2-Clause (licenses\mpdecimal\COPYRIGHT.txt)
  Files:   _internal\_decimal.pyd
  Source:  https://www.bytereef.org/mpdecimal/

liblzma, from XZ Utils (compiled into Python's lzma module)
  Licence: public domain in the XZ Utils releases before 5.6, and the BSD
           Zero Clause License (0BSD) from 5.6 on. Neither requires a notice
           or a licence text to be shipped.
  Files:   _internal\_lzma.pyd
  Source:  https://tukaani.org/xz/

Microsoft Visual C++ runtime and Universal C runtime
  Licence: Microsoft redistributable runtime files, shipped as part of the
           Python, PySide6 and numpy builds under Microsoft's redistribution
           terms (see licenses\Python\LICENSE.txt, "Additional Conditions for
           this Windows binary build")
  Files:   VCRUNTIME140*.dll, MSVCP140*.dll, ucrtbase.dll and
           api-ms-win-*.dll in _internal\, _internal\PySide6\,
           _internal\shiboken6\ and _internal\numpy.libs\
  Source:  https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist

numpy
  Licence: BSD 3-Clause, with bundled parts under 0BSD, MIT, Zlib and CC0
  Text:    _internal\numpy-<version>.dist-info\licenses\
  Files:   _internal\numpy\ and _internal\numpy.libs\, which holds OpenBLAS
           (BSD 3-Clause) as libscipy_openblas64_*.dll
  Source:  https://numpy.org/

PyOpenGL
  Licence: BSD 3-Clause style (licenses\PyOpenGL\license.txt)
  Files:   Python code inside Bermake.exe
  Source:  https://github.com/mcfletch/pyopengl

mapbox-earcut
  Licence: ISC (licenses\mapbox_earcut\)
  Files:   _internal\mapbox_earcut\
  Source:  https://github.com/skogler/mapbox_earcut_python

PyInstaller bootloader
  Licence: GPL v2 or later with the bootloader exception
           (licenses\pyinstaller\)
  Files:   Bermake.exe
  Source:  https://pyinstaller.org/

Mesa 3D
  Licence: MIT (text below)
  Files:   _internal\mesa\opengl32sw.dll, _internal\mesa\libgallium_wgl.dll
  Source:  https://mesa3d.org/
           Windows build by pal1000/mesa-dist-win:
           https://github.com/pal1000/mesa-dist-win

LLVM (statically linked into Mesa's libgallium_wgl.dll)
  Licence: Apache License 2.0 with LLVM Exceptions
           (licenses\LLVM\LICENSE.TXT)
  Files:   _internal\mesa\libgallium_wgl.dll, where llvmpipe uses LLVM to
           compile shaders for the CPU
  Source:  https://llvm.org/
           https://github.com/llvm/llvm-project
